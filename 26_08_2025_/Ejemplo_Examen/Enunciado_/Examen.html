Examen - Gaming Dojo

Requisitos:
  • Crear la captura de pantalla anterior en HTML/CSS/JS.
  • Todo el texto debe estar en formato HTML a menos que sea parte de la imagen.
  • Revisa las imágenes descargables para ver qué texto ya proporcionan.
  • Los botones enlaces deben estar en HTML y no agregarse como imágenes.
Notas:
  • Las imágenes utilizadas están disponibles para descargar en images.zip.
  • Trabaja en el ejercicio anterior y carga tu código/archivos (comprime los archivos antes de subirlos).
  • Para evitar que otros estudiantes copien tu trabajo, no publiques el código en GitHub ni en sitios compartidos.
  • Para minimizar descuentos de puntaje, carga todos los requisitos completos (HTML, CSS, JS, imágenes).
  • No es necesario crear una demostración en video para el examen de Cinturón amarillo.
  • Si tienes problemas para cargar archivos en la aplicación del examen, no desbloquees otro examen: envía el archivo por correo a tu instructor.
  • Todos los archivos deben entregarse para recibir calificación; la omisión de algún archivo resultará en reprobación automática.
